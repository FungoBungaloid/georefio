about=Batch georeference multiple images automatically using Vision AI for location estimation and MatchAnything for feature matching.
    .
    Features:
    - Batch processing of entire folders of images
    - Vision AI location estimation (OpenAI GPT-5, Anthropic Claude)
    - Automatic basemap selection per image
    - Progressive quality backoff for challenging imagery
    - Support for pre-geocoded images with loose positioning
    - Flight path/centroid shapefile input support
    - Customizable LLM prompts for location extraction
    - Cloud Optimized GeoTIFF (COG) output with DEFLATE compression
    - Exportable control points (.points format)
    .
    Requirements:
    - QGIS 3.22 or higher (Windows, macOS, Linux)
    - Magic Georeferencer plugin (required dependency)
    - Python 3.9+ (bundled with QGIS)
    - 8 GB RAM minimum, 16 GB recommended
    - ~2 GB disk space for model cache
    - Optional: NVIDIA GPU with CUDA for faster processing
    - API key for OpenAI or Anthropic (for location estimation)
    .
    Supported Input Modes:
    - Folder of ungeoreferenced images
    - Images with rough location metadata (EXIF, World files)
    - Flight path shapefiles with centroids
    .
    Platform Support: Works on Windows, macOS, and Linux.
    .
